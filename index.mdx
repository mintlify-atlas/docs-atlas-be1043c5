Ory is a global identity and access management platform built on open-source software. Whether you need user login flows, OAuth2 authorization, fine-grained permissions, or a zero-trust access proxy, Ory provides production-ready infrastructure that runs on the Ory Network or on your own servers.

## Platform overview

Ory Network provides all the building blocks for modern identity infrastructure. Each component is open-source and available for self-hosting.

<CardGroup cols={2}>
  <Card title="Ory Identities" icon="id-card" href="/identities/overview">
    Full-featured identity management based on Ory Kratos. Supports passwords, passkeys, social sign-in, MFA, and more.
  </Card>
  <Card title="Ory OAuth2 & OIDC" icon="shield-check" href="/oauth2-oidc/overview">
    OpenID Certified® OAuth2 and OIDC provider based on Ory Hydra. Powers SSO, API delegation, and token management.
  </Card>
  <Card title="Ory Permissions" icon="diagram-project" href="/permissions/overview">
    Zanzibar-inspired permissions engine based on Ory Keto. Supports RBAC, ABAC, and custom relationship models.
  </Card>
  <Card title="Open Source" icon="code-branch" href="/oss/open-source">
    All Ory core services are Apache 2.0 licensed. Run Kratos, Hydra, Keto, and Oathkeeper on your own infrastructure.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Create an Ory Network project">
    Sign up at [console.ory.sh](https://console.ory.sh) and create a free developer project. Your project provides a dedicated API endpoint and the full Ory stack.
  </Step>
  <Step title="Install the Ory CLI">
    The Ory CLI connects your local environment to your project and lets you manage identities, OAuth2 clients, and permissions from the terminal.
    ```bash
    npm install --global @ory/cli
    ory auth
    ```
  </Step>
  <Step title="Integrate authentication">
    Use the Ory SDK or REST API to add login, registration, and session management to your application. Ory provides pre-built UI flows or fully headless APIs for custom UIs.
  </Step>
  <Step title="Configure your identity model">
    Define custom identity schemas using JSON Schema to capture the user fields your application needs — email, name, phone number, or any custom attribute.
  </Step>
</Steps>
