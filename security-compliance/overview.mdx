## Data residency

Ory Network lets you choose where your identity data is stored. For projects serving European users, you can host all personal data on EU-based servers to support GDPR compliance.

Cross-border transfers of personal data outside the EU are restricted under GDPR. By selecting EU data residency, your identity data remains within the EU jurisdiction throughout its lifecycle.

## GDPR compliance posture

Ory Network was designed with GDPR requirements in mind:

- **Data portability** — Ory's APIs let you retrieve all personal data for a specific identity.
- **Right to deletion** — Delete an identity and all associated personal data through the admin API.
- **Data minimization** — Default identity schemas collect only what is needed for basic account operations.
- **Accuracy** — The self-service account settings flow lets users view and update their own data.
- **Integrity and confidentiality** — All traffic is encrypted in transit using TLS 1.2 or higher. Data at rest is encrypted with AES-256. Passwords are stored as salted bcrypt hashes.
- **Breach response** — Ory has policies for notifying affected parties within the GDPR-mandated 72-hour window in the event of a data breach.

<Note>
  GDPR compliance is a shared responsibility. Ory provides the infrastructure and APIs; you are responsible for how your application collects consent, handles data subject requests, and processes personal data in your own systems.
</Note>

## Data protection measures

**Vulnerability management** — Ory embeds vulnerability scanning into its CI/CD pipelines and scans all containers at build time. Running containers in production clusters are scanned continuously.

**Penetration testing** — Third-party penetration tests are conducted quarterly.

**Bug bounty program** — Ory runs a private bug bounty program through HackerOne. See [Bug bounty program](#bug-bounty-program) below.

**Secure cloud infrastructure** — Ory Network runs on Google Cloud Platform.

**Logging and audit trails** — Comprehensive logging enables forensic analysis of potential incidents.

**Backup strategy** — Regular encrypted backups are stored to protect against data loss.

## Token formats and prefixes

Ory uses consistent, identifiable prefixes on all tokens and keys so that security scanners can detect leaked credentials automatically.

| Token type | Prefix | Notes |
|---|---|---|
| OAuth 2.0 Access Token | `ory_at_` | Not applied when using JWTs |
| OAuth 2.0 Refresh Token | `ory_rt_` | Not applied when using JWTs |
| OAuth 2.0 Authorization Code | `ory_ac_` | Not applied when using JWTs |
| Session cookie | `ory_session_` | Scoped to configured cookie domain |
| Session token | `ory_st_` | Used when cookies are unavailable |
| Logout token | `ory_lo_` | Issued on session termination |
| Project API key | `ory_pat_` or `ory_apikey_` | Admin API access |
| Workspace API key | `ory_wak_` | Management API access |
| Ory internal cookies | `ory_` | CSRF protection, load balancing |

<Tip>
  Configure your secret scanning tools (GitHub Advanced Security, GitGuardian, etc.) to flag any of these prefixes to prevent credential leakage in source code or logs.
</Tip>

## Bug bounty program

Ory runs a private bug bounty program through HackerOne. To participate, [create a HackerOne account](https://hackerone.com/sign_up) and request access at [security@ory.com](mailto:security@ory.com).

**Response timelines:**

- 1–2 business days to first response
- 3–5 business days from submission to triage
- 3–5 business days from triage to bounty decision

**Reward amounts:**

| Severity | Reward |
|---|---|
| Low | $100 |
| Medium | $350 |
| High | $1,000 |
| Critical | $3,000 |

**Out-of-scope items include:** attacks requiring physical device access, vulnerabilities in intentionally public infrastructure (docs, marketing site), missing rate limiting, software version disclosure, open redirects without demonstrated additional impact, and attacks through user-controlled runtime environments in self-hosted deployments.

Please do not discuss vulnerabilities outside the HackerOne program without written consent from Ory.
