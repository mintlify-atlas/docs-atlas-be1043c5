Ory is an open-source-first company. Every major product in the Ory ecosystem is published under the [Apache 2.0 license](https://www.apache.org/licenses/LICENSE-2.0), meaning you can inspect the source, contribute, and self-host without restriction. The commercial Ory Network and Ory Enterprise License are built directly on top of the same open-source code, sharing the same APIs, configuration, and behavior.

## Core server projects

These are the four fully-featured identity and access control servers. Each one ships as a small, stateless binary or Docker image that runs anywhere.

<CardGroup cols={2}>
  <Card title="Ory Kratos" icon="user" href="https://github.com/ory/kratos">
    Identity management server. Handles login, registration, MFA, account recovery, session management, and profile updates without you writing a single authentication flow from scratch.
  </Card>
  <Card title="Ory Hydra" icon="key" href="https://github.com/ory/hydra">
    OAuth 2.0 and OpenID Connect provider. Issues access, refresh, and ID tokens in a certified, secure manner and integrates with any existing identity system.
  </Card>
  <Card title="Ory Keto" icon="shield" href="https://github.com/ory/keto">
    Permission server based on Google Zanzibar. Defines and evaluates fine-grained access control policies using relationship-based access control (ReBAC).
  </Card>
  <Card title="Ory Oathkeeper" icon="lock" href="https://github.com/ory/oathkeeper">
    Identity and Access Proxy. Sits in front of your services and enforces authentication and authorization rules — no code changes required in upstream services.
  </Card>
</CardGroup>

## Additional projects

<CardGroup cols={2}>
  <Card title="Ory Polis" icon="building" href="https://github.com/ory/polis">
    Enterprise Single Sign-On bridge. Translates SAML into standard OAuth 2.0 / OIDC flows, making it easy to connect B2B customers using Entra ID, Okta, or Google Workspace.
  </Card>
  <Card title="Ory Elements" icon="layout" href="https://github.com/ory/elements">
    UI component library for Ory self-service flows. Pre-built components for login, registration, settings, verification, recovery, and OAuth2 consent that you can drop into any frontend.
  </Card>
</CardGroup>

## License and commercial offerings

All Ory server projects are licensed under **Apache 2.0**. You may use, modify, and redistribute them freely, including in commercial products.

The Ory Network (managed cloud) and Ory Enterprise License (self-hosted, enterprise features) are commercial offerings that fund ongoing open-source development. They are built on the same codebase and expose the same APIs. Open source is not a stepping stone — it remains the foundation.

<Note>
  Open source remains at the core of Ory. Commercial offerings like Ory Network and the Ory Enterprise License exist to sustain and accelerate open-source development, not to replace it.
</Note>
